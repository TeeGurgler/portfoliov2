# Andres Jauch – Personal Portfolio

Das persönliche Portfolio von Andres Jauch, live unter https://www.andresjauch.ch (Vercel-Vorschau: https://portfolio-lemon-seven-52.vercel.app).

## Tech-Stack
* Hosting & Deployment: Vercel
* Domain & DNS: Hostpoint DNS (A- & CNAME-Records)
* Framework: Next.js / React
* Styling: Tailwind CSS

## Lokale Entwicklung
1. Repository klonen: `git clone https://github.com/DEIN-BENUTZERNAME/DEIN-REPO.git`
2. Projektverzeichnis öffnen: `cd DEIN-REPO`
3. Abhängigkeiten installieren: `npm install` (oder `pnpm install` / `yarn install`)
4. Entwicklungsserver starten: `npm run dev`
5. Lokal öffnen unter: http://localhost:3000
